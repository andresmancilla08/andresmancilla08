## Cómo trabajo

- **Sistema de diseño primero.** Tokens antes que componentes, componentes antes que pantallas — por eso estas apps se ven intencionadas y no ensambladas.
- **La IA como compañera, el código como fuente de verdad.** El modelo propone y razona; los números, las reglas y la seguridad viven en el código y en las pruebas.
- **Publicar para usuarios reales.** Todo lo de arriba está desplegado y en uso, no es un repo de tutorial.
- **Multiidioma por defecto.** Sin textos fijos en el código; varias de estas apps salen en tres idiomas.
