- **Claude Code as my main tool.** I design, build and ship complete products from zero to production with it — UI, logic, tests, security rules and deployment.

- **AI features in production.** Proactive financial insights and receipt OCR in Spendia, and a conversational English tutor with neural voice in Parlo — with every figure computed in code, so the model never invents numbers.
